# PTM-1006: secret-keychain-missing

```text
✗ <target>: secret reference keychain:service/item cannot be read from the keychain
  cause: no such item
→ store the secret as service "service", item "item" in the OS keychain of the user pentym runs as
```

## Cause

A secret reference `keychain:service/item` names an item that is not in the OS keychain of the user pentym runs as, or the keychain cannot be reached (for example, no Secret Service is running on Linux).

## Impact

The operation that needed the secret does not run.

## Fix

Store the item in the keychain of the user pentym runs as:

- macOS: Keychain Access, as a password item with that service and account.
- Windows: Credential Manager, as a generic credential.
- Linux: a Secret Service such as GNOME Keyring or KeePassXC.

A service account often has a different keychain from your own login. On servers without a keychain, use `env:` or `file:` references instead.
