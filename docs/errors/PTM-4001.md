# PTM-4001: key-slot-unlock-failed

```text
✗ key slot <id> (<label>) did not unlock: wrong passphrase
→ check the passphrase for this slot, or unlock with another slot (pentym key list)
```

The message says "age identity" or "recovery code" for those kinds of slot.

## Cause

The passphrase, age identity or paper recovery code given for a key slot is not the one the slot was created with. A recovery code may be typed in upper or lower case, with or without the dashes.

## Impact

The command stops before reading the repository; nothing is changed.

## Fix

Check the secret reference or the value you typed for this slot. If it is lost, unlock with another full slot or the paper recovery code, then remove the old slot and add a new one with `pentym key remove` and `pentym key add`.
