# PTM-7003: pack-unindexed

```text
! data/4f/4f2a…: pack is in no index file; pentym repo rebuild-index adds it, prune removes it if unused
→ pentym repo rebuild-index
```

## Cause

A pack exists that no index file lists. A backup that stopped after uploading a pack and before writing its index file leaves one; so does an index file that was lost.

## Impact

None for the data already indexed. The pack uses storage, and its chunks cannot be found until it is indexed: if an index file was lost, snapshots may report missing chunks ([PTM-7001](PTM-7001.md)).

## Fix

Run `pentym repo rebuild-index` to index every pack again. If no snapshot uses the pack, prune removes it.
