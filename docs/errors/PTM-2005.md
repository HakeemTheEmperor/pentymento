# PTM-2005: postgres-wal-level-minimal

```text
✗ prod-pg: wal_level is minimal, which allows no base backups over replication
→ set wal_level = replica in postgresql.conf and restart Postgres
```

## Cause

With `wal_level = minimal`, Postgres writes too little WAL for replication, so it refuses base backups over the replication protocol and continuous capture.

## Impact

pentym cannot back up the target.

## Fix

Set `wal_level = replica` (the default since Postgres 10) in `postgresql.conf` and restart Postgres. `logical` also works.
