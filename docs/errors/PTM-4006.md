# PTM-4006: one-full-key-slot

```text
! the repository has only one full key slot
  losing its passphrase or identity would make every backup unreadable
→ pentym key add, or pentym key export --paper
```

`pentym check` reports the same condition as `slots/: only 1 full key slot`.

## Cause

Only one full key slot is left: one passphrase, age identity or paper recovery code can unlock the repository's private key. `pentym init` creates two, so a slot was removed since.

## Impact

Nothing is broken now. If that one secret is lost, every backup in the repository becomes unreadable, by design: nothing else can decrypt it.

## Fix

Add a second way to unlock, then check it works:

- `pentym key add` for another passphrase, or `pentym key add --age-recipient age1…` for an age identity;
- `pentym key export --paper` for a paper recovery code to keep offline.
