# PTM-7004: object-stray

```text
! data/zz/notes.txt: object under data/ is not named like a pack
→ remove the object if nothing else wrote it; see docs/errors/PTM-7004
```

## Cause

`pentym check` found an object pentym did not write where it keeps packs or log segments: its name does not have the form pentym uses there (see [the repository format](../repository-format.md)).

## Impact

None: pentym ignores it. It uses storage, and it may show that something else writes into the repository's bucket or directory.

## Fix

Find out what wrote it. If nothing needs it, delete it; keep other tools and people out of the repository's location.
