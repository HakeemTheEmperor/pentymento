# PTM-4002: last-full-slot

```text
✗ key slot <id> (<label>) is the last full slot
  removing it would make every backup unreadable
→ pentym key add (add another full slot or a paper key first)
```

## Cause

`pentym key remove` was asked to remove the only full slot: the only way left to unlock the repository's private key.

## Impact

Nothing is removed. Without a full slot, no backup in the repository could ever be restored.

## Fix

Add another full slot or a paper recovery key with `pentym key add` or `pentym key export --paper`, check that it unlocks, then remove the old one.
