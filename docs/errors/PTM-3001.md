# PTM-3001: repository-format-newer

```text
✗ repository format 2 is newer than this pentym understands (format 1)
  this pentym cannot read or write the repository; nothing was changed
→ upgrade pentym to the version that created or upgraded this repository
```

## Cause

The repository was created or upgraded by a newer pentym, with `pentym repo upgrade`. A binary never reads or writes a repository format newer than it understands, so an old agent, CLI or CI job cannot corrupt it.

## Impact

This command does nothing. Backups and restores work again once every binary using the repository is updated.

## Fix

Update this machine's pentym to the release that matches the repository format. Upgrade every binary that uses the repository (agents, CLIs, CI jobs) before running `pentym repo upgrade`.
