# PTM-6004: restore-object-missing

```text
✗ prod-pg: table public.orderz did not exist at the restore point
  nothing was loaded into production
→ check the table's name and schema, or restore to an earlier point
```

## Cause

A table named with `--table` is not in the database at the restore point: its name or schema is misspelt (`orders` means `public.orders`; name another schema as `billing.invoices`), it was created after the point, or it had already been dropped by then. The same ID is used when the table's schema does not exist in production, so the table cannot be loaded there.

## Impact

Nothing was loaded into production. The side instance was removed.

## Fix

Check the name, case included, and the schema. If the table was created after the point, restore to a later point. If the schema is missing in production, create it, then restore again.
