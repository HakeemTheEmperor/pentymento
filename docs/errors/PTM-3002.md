# PTM-3002: repository-not-found

```text
✗ no repository found at this location (no config object)
→ check the repository location in the config, or create one with pentym init
```

## Cause

The configured repository location has no `config` object: the path, bucket or prefix is wrong, the credentials point at another bucket, or the repository was never created.

## Impact

The command does not run.

## Fix

Check the repository location and storage credentials in the config. To create a new repository there, run `pentym init`.
