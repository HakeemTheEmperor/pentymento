# PTM-1007: secret-command-failed

```text
✗ <target>: secret reference cmd:<helper> failed
  cause: exit status 1: <first part of the helper's error output>
→ run the helper by hand as the user pentym runs as and check its output
```

## Cause

The helper named by a `cmd:` reference exited with an error, printed nothing, ran for more than 30 seconds, or could not be started.

## Impact

The operation that needed the secret does not run.

## Fix

Run the helper yourself as the user pentym runs as and check that it prints only the secret. Helpers such as `op` or `vault` usually need a session or token in that user's environment. The command runs without a shell: quote arguments that contain spaces with single or double quotes.
