# PTM-1009: repository-not-configured

```text
✗ no repository location in /etc/pentym/config.yaml
→ set repository.path to an absolute directory, or repository.s3 to a bucket, in the config
```

## Cause

The command works on the repository, but the config has neither `repository.path` nor `repository.s3`.

## Impact

Nothing was read or changed.

## Fix

Add the repository location to the config, then run the command again:

```yaml
repository:
  path: /var/lib/pentym/repo
```

or, for an S3-compatible bucket:

```yaml
repository:
  s3:
    bucket: acme-pentym
    region: eu-west-1
```

A path must be absolute. See [Configuration](../reference/config.md#repository).
