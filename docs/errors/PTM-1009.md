# PTM-1009: repository-not-configured

```text
✗ no repository location in /etc/pentym/config.yaml
→ set repository.path to an absolute directory in the config
```

## Cause

The command works on the repository, but the config has no `repository.path`.

## Impact

Nothing was read or changed.

## Fix

Add the repository location to the config, then run the command again:

```yaml
repository:
  path: /var/lib/pentym/repo
```

The path must be absolute. See [Configuration](../reference/config.md#repository).
