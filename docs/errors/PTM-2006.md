# PTM-2006: postgres-replication-refused

```text
✗ prod-pg: the server refuses replication connections from pentym_backup
  base backups use a replication connection
→ allow it in pg_hba.conf with a line for the replication database, then reload Postgres
```

## Cause

`pg_hba.conf` has no line that allows the backup role to open a replication connection from pentym's host. Replication connections match only lines whose database field is `replication`; a line for `all` databases does not cover them.

## Impact

Base backups fail. Normal connections, such as for the inventory, may still work.

## Fix

Add a line for the replication database, from pentym's address, and reload Postgres (`SELECT pg_reload_conf();`):

```text
host  replication  pentym_backup  10.0.0.9/32  scram-sha-256
```

Then run `pentym doctor <target>`.
