# PTM-4003: insecure-test-mode-remote

```text
✗ --insecure-test-mode works only with a local repository
  an unencrypted repository on remote storage would expose every backup
→ use a local path for development, or drop --insecure-test-mode
```

## Cause

`--insecure-test-mode` creates a repository without encryption. It exists only for local development and tests, so it is refused for S3-compatible storage.

## Impact

No repository is created.

## Fix

Use a local directory for development, or create a normal, encrypted repository without the flag.
