# PTM-3003: repository-exists

```text
✗ a repository already exists at this location
→ use the existing repository, or choose an empty location
```

## Cause

`pentym init` was run against a location that already holds a repository. pentym never overwrites one.

## Impact

Nothing is written; the existing repository is unchanged.

## Fix

To use the existing repository, point the config at it and unlock it with one of its key slots. To start a new one, choose an empty path, bucket or prefix.
