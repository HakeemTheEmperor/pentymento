# PTM-2012: mongodb-sharded-unsupported

```text
✗ prod-mg: the uri points at a mongos router; sharded clusters are not supported
→ point uri at a replica set or a standalone server
```

## Cause

The target's `uri` connects to a `mongos` router, which fronts a sharded cluster. pentym v1 backs up replica sets and standalone servers only.

## Impact

pentym does not back up the target. A consistent backup of a sharded cluster needs coordination across the shards and the config servers that pentym does not provide.

## Fix

Point `uri` at a replica set or a standalone server. For a sharded cluster, keep using a tool built for sharded backups.
