# PTM-4004: no-unlock-secret

```text
✗ cannot unlock the repository: no terminal to ask for a passphrase, and no repository.key in the config
→ set repository.key to a reference such as env:PENTYM_KEY, or run the command in a terminal
```

## Cause

The command needs to unlock the repository with a key slot. In a terminal, pentym asks for the passphrase, recovery code or age identity. This run has no terminal (a script, cron or CI job), and the config has no `repository.key` to read it from.

## Impact

Nothing was read or changed.

## Fix

Run the command in a terminal, or point `repository.key` at the secret:

```yaml
repository:
  path: /var/lib/pentym/repo
  key: env:PENTYM_KEY
```

The value is a [secret reference](../reference/config.md#secrets), never the passphrase itself. A value that starts with `AGE-SECRET-KEY-` is used as an age identity; anything else as a passphrase or paper recovery code.
