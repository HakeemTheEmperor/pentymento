# PTM-1004: secret-env-unset

```text
✗ <target>: secret reference env:NAME: environment variable NAME is not set
→ set NAME in pentym's environment, or change the reference
```

## Cause

A secret reference `env:NAME` points to an environment variable that is not set, or is empty, in pentym's environment.

## Impact

The operation that needed the secret does not run.

## Fix

Set the variable where pentym runs: in the shell, the CI job's secrets, the service's environment (systemd `Environment=`, launchd `EnvironmentVariables`), or the Kubernetes Deployment. Services do not see variables set in your login shell.
