# PTM-1002: plaintext-secret-file-readable

```text
✗ <file> holds plaintext secrets and other users can read it
  anyone on this machine can read those secrets
→ chmod 600 <file>
```

## Cause

`allow_plaintext_secrets: true` is set and a config file holds a secret value, but the file is readable by other users: its group or other read bits are set (Linux, macOS), or its access list lets Everyone, Users or Authenticated Users read it (Windows).

## Impact

pentym refuses to load the config, so the command does not run.

## Fix

Make the file readable only by the user pentym runs as:

- Linux and macOS: `chmod 600 <file>`.
- Windows: open the file's Properties, then Security, and remove read access for Everyone, Users and Authenticated Users.

Better still, replace the plaintext value with a reference (see [PTM-1001](PTM-1001.md)).
