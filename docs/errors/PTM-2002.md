# PTM-2002: postgres-version-unsupported

```text
✗ prod-pg: Postgres 15.8 is not supported; pentym supports 16, 17, 18
→ upgrade the server to a supported major version
```

## Cause

The target runs a Postgres major version pentym does not support. pentym supports Postgres 16, 17 and 18.

## Impact

pentym does not back up the target, because it has not been tested against that version's base-backup protocol and WAL format.

## Fix

Upgrade the server to a supported major version. Until then, keep backing it up with the tools you use today.
