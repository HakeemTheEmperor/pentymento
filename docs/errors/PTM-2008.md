# PTM-2008: mongodb-version-unsupported

```text
✗ prod-mg: MongoDB 6.0.19 is not supported; pentym supports 7.0, 8.0, 9.0
→ upgrade the server to a supported version
```

## Cause

The target runs a MongoDB release pentym does not support. pentym supports MongoDB 7.0, 8.0 and 9.0.

## Impact

pentym does not back up the target, because it has not been tested against that release's oplog and `mongodump` behaviour.

## Fix

Upgrade the server to a supported release. Until then, keep backing it up with the tools you use today.
