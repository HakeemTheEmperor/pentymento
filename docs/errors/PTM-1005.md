# PTM-1005: secret-file-unreadable

```text
✗ <target>: secret reference file:/path cannot be read
  cause: the file does not exist
→ check that /path exists and is readable by pentym, or change the reference
```

## Cause

A secret reference `file:/path` points to a file that does not exist, that pentym's user cannot read, or that is empty.

## Impact

The operation that needed the secret does not run.

## Fix

Check the path and permissions as the user pentym runs as. For Docker and Kubernetes secrets, check that the secret is mounted at that path in this container. One trailing newline in the file is ignored.
