# PTM-1003: config-invalid

```text
✗ config <file> line <n>: <problem>
→ correct line <n> of <file>
```

## Cause

The config file, one of its includes, or a `PENTYM_…` environment override is not valid: a YAML syntax error, an unknown key, a value of the wrong type, an include cycle, or a target without a supported engine.

## Impact

pentym refuses to load the config, so the command does not run.

## Fix

Correct the line or variable the message names. Keys are matched exactly, so check the spelling against the [config reference](../reference/config.md). For an environment override, correct or unset the variable.
