# PTM-1008: config-not-found

```text
✗ config file <path> not found
→ create it, or point to the config with --config or PENTYM_CONFIG
```

## Cause

There is no file at the config path, or a file listed under `include` does not exist. Without `--config` or `PENTYM_CONFIG`, pentym reads:

| System | Path |
| --- | --- |
| Linux | `/etc/pentym/config.yaml` |
| macOS | `/usr/local/etc/pentym/config.yaml` |
| Windows | `%ProgramData%\pentym\config.yaml` |

## Impact

The command does not run.

## Fix

Pass `--config <path>`, set `PENTYM_CONFIG`, or create the file at the default path. For an include, correct the path in the including file; relative include paths are relative to that file.
